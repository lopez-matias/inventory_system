# Changelog

This project follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and Semantic Versioning.

## [1.0.0] - 2026-09-02

### Added

- Product and location management with logical deactivation.
- Inventory levels per product and location.
- Entry, exit, adjustment, and atomic transfer movements.
- Validation that prevents negative stock.
- Dashboard metrics, alerts, location summaries, and recent movements.
- Responsive interface built with HTML, CSS, and vanilla JavaScript.
- REST API with OpenAPI documentation.
- Alembic migrations, generic demo data, and business-rule tests.
